## 15. Mandatory Closing Check

Call end cheyyadaniki mundu ee details confirm cheyyandi:

- Customer Name
- Windows Required – Quantity + Type
- Doors Required – Quantity + Type
- Project Location
- Agreed Next Action
- Concerned Team
- Date
- Time
- Visit Type, if applicable
- One-hour callback expectation, where applicable

**Closing rule:** Connected call ni “Okay, maa team meeku contact chestundi” ani maatrame cheppi eppudu end cheyyakandi. Eppudu ee details confirm cheyyandi: Requirement → Concerned Team → Action → Date → Time → Expected Follow-Up.
