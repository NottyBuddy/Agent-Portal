## 15. Mandatory Closing Check

Call end karne se pehle ye details confirm karein:

- Customer Name
- Windows Required – Quantity + Type
- Doors Required – Quantity + Type
- Project Location
- Agreed Next Action
- Concerned Team
- Date
- Time
- Visit Type, if applicable
- One-hour callback expectation, where applicable

**Closing rule:** Connected call ko sirf “Okay, hamari team aapse contact karegi” kehkar kabhi end na karein. Hamesha ye confirm karein: Requirement → Concerned Team → Action → Date → Time → Expected Follow-Up.
